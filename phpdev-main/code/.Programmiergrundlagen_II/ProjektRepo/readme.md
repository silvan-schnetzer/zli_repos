# Grade Calculator

## Description
This is a simple PHP program that allows users to enter grades and calculates the average of all entered grades.

All entered grades are saved in a text file called `grades.txt`.

## Features
- Enter multiple grades.
- Type `x` to stop entering grades.
- Calculates the average of all grades.
- Saves grades in `grades.txt`.
- Only accepts grades between 0 and 6.

## Requirements of the Assignment
- **File system:** Uses `grades.txt` to save the grades.
- **Type functions:** Uses functions like `is_numeric()` and `(int)`.
- **UDF:** Uses the own function `askgrades()` with parameters and a return value.
- **Loop:** Uses a `do-while` loop to ask for grades.
- **Conditions:** Uses `if` statements to check the entered grades.
- **Regular expressions:** Not used (optional).
